# Davidkovach-fuentes Tap

## How do I install these formulae?

`brew install davidkovach-fuentes/tap/rt`
`brew install davidkovach-fuentes/tap/SASH`

Or `brew tap davidkovach-fuentes/tap` and then `brew install rt` or `brew install SASH`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "davidkovach-fuentes/tap"
brew "rt"
brew "SASH"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
